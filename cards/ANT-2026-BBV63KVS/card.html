ANT-2026-BBV63KVS: Heap-buffer-overflow READ in FFmpeg APV decoder via malformed APV input

A heap-buffer-overflow read occurs in FFmpeg's APV (AV_CODEC_ID_APV) decoder when processing fuzzer-generated input.

Target

Project: ffmpeg/ffmpeg
Location: libavcodec/apv_decode.c:apv_decode_tile_component

Technical Details

Crash signature: ASAN heap-buffer-overflow READ
