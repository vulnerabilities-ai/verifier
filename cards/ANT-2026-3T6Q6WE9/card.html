ANT-2026-3T6Q6WE9: Integer overflow in scaletempo audio filter leading to heap buffer overflow via signed integer overflow in stride computation

A signed integer overflow in the stride computation of the scaletempo audio filter results in a heap buffer overflow.

Target

Project: mpv-player/mpv
Location: scaletempo audio filter (stride computation)
Discovery: static analysis — not yet dynamically reproduced

Technical Details

The stride size computation in the scaletempo filter uses signed integer arithmetic that can overflow, producing an incorrect (likely negative or wrapped) stride value. This miscomputed stride is then used for buffer indexing or allocation, leading to out-of-bounds heap access.

Reproduction

This finding was identified by static analysis and has not yet been dynamically reproduced. The Technical Details section above describes the code path; a trigger input is not included.
